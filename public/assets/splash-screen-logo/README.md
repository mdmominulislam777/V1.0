# HighFy TV - Splash Screen Logo

This folder stores the official brand logo displayed on the initial loading/splash screen.

### Specifications:
- **Primary File**: `splash_logo.png`
- **Recommended Dimensions**: 512x512 (Square 1:1)
- **Format**: High-resolution Transparent PNG or WebP
- **Usage**: Displayed inside the central splash card (`#cricfy-splash-logo-img`) while the app loads.
