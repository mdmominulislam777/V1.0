# HighFy TV - Drawer Menu Logo

This folder stores the brand logo displayed at the top of the side drawer (slide menu).

### Specifications:
- **Primary File**: `drawer_logo.png`
- **Recommended Dimensions**: 256x256 or 512x512 (Square 1:1)
- **Format**: High-resolution Transparent PNG or WebP
- **Usage**: Displayed inside the drawer header (`#drawer-header-logo-img`).
